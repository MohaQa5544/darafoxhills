# نظام تقييم أداء المقاولين والاستشاريين — الإدارة العامة للأوقاف

مجلد مشروع «66 - 2610 تقييم المقاولين والاستشاريين». البرنامج اسمه «سجل الأداء»، ويعمل بطريقتين من الكود نفسه:

1. **أوفلاين**: يُفتح `app/index.html` من مجلد دروب بوكس المشترك، والبيانات ملفات JSON في `data/` أو في المتصفح.
2. **سحابي (رابط على Vercel)**: الواجهة نفسها مع خادم في `app/api` و`app/lib`، وبيانات مشتركة لكل الفريق في متجر Vercel Blob خاص. عند فتح البرنامج من رابط يكتشف الخادم تلقائياً ولا تظهر شاشة اختيار مكان البيانات.

- الخطة الكاملة: https://claude.ai/artifact/9wPsxUonAoeDSsZQoKv3ak — ونسخة منها دون أسماء المستخدمين في `docs/plan.html`.

## محتوى المجلد
- `app/` — البرنامج: `index.html`، `boot.js`، `core.js`، `store.js` (مجلد / متصفح / سحابي)، `screens.js`، `eval.js`، `review.js`، `reports.js`، `settings.js`، `bank.js` (بنك الأسئلة والأوزان الافتراضية)، `texts.js` (نصوص الخطابات)، `logos.js`، `app.css`.
- `app/api/` — دوال Vercel: `rpc` (الدخول والبيانات)، `file` (المرفقات)، `health`.
- `app/lib/` — منطق الخادم: `core.mjs` (الدخول، الصلاحيات، التخزين المتزامن، الاستيراد والتصدير)، `blob-store.mjs` (Vercel Blob)، `runtime.mjs` (التهيئة من متغيرات البيئة).
- `app/vercel.json` — رؤوس الأمان (CSP وغيرها) وإعدادات الدوال؛ `app/package.json` يثبّت إصدار `@vercel/blob`.
- `app/brand/` — خلفية الورق الرسمي الطولية، والخلفية العرضية للتقارير، والشعارات.
- `dev/` — خادم تطوير محلي (`server.mjs`) بمحرك تخزين يحاكي Vercel Blob (`fs-store.mjs`) ومستخدمي اختبار (`seed.example.json`).
- `test/` — `e2e.js` (الأوفلاين)، `e2e-cloud.js` (الواجهة السحابية كاملة في المتصفح)، `api-cloud.mjs` (اختبارات الخادم والأمان).

## النسخة السحابية: كيف تعمل
- **التخزين**: مستند واحد مضغوط `ev/db.json.gz` في متجر Blob خاص، يُكتب بشرط ETag (تزامن تفاؤلي) فلا تضيع تعديلات مستخدمَين متزامنين، وتعديل سجل قديم يُرفض برسالة «عدّل مستخدم آخر…» بدل الكتابة فوقه. المرفقات ملفات خاصة في `ev/files/` (حتى 4 ميجابايت للملف). نسخة احتياطية يومية تلقائية في `ev/backups/` (آخر 35 يوماً)، وسجل التدقيق يُؤرشف في `ev/audit/`.
- **الدخول**: كلمات المرور مجزأة PBKDF2 على الخادم ولا تصل إلى المتصفح، والجلسة رمز موقّع صالح 12 ساعة ويُلغى عند تغيير كلمة المرور أو إعادة تعيينها أو تعطيل الحساب. كل مستخدم يبدأ بكلمة مرور مؤقتة فريدة ويُلزم بتغييرها (8 أحرف على الأقل تجمع حروفاً وأرقاماً)، ومحاولات الدخول الخاطئة المتكررة تُوقَف مؤقتاً.
- **الصلاحيات على الخادم**: حساب المتابعة للاطلاع فقط؛ المهندس يقيّم ويرفق لعقوده ولا يرى مسودات زملائه (حسب إعداد الرؤية)؛ المراجع يعيد التقييم ولا يغيّر درجاته؛ الاعتماد وتغيير حالة الشركة للمعتمدين؛ المستخدمون والإعدادات والاستيراد لمدير النظام.
- **نقل بيانات الأوفلاين**: من «الإعدادات ← البيانات والنسخ الاحتياطي» يصدّر المدير نسخة من البرنامج الأوفلاين ثم يستوردها في السحابي؛ من غيّر كلمة مروره في الأوفلاين يدخل بها، ومن بقي على 123456 تُنشأ له كلمة مؤقتة جديدة تظهر للمدير.

## متغيرات البيئة على Vercel
| المتغير | الغرض |
|---|---|
| `SESSION_SECRET` | مفتاح توقيع الجلسات، 32 حرفاً عشوائياً أو أكثر |
| `SEED_USERS` | قائمة المستخدمين الأولية بتجزئات كلمات المرور المؤقتة (تُستخدم مرة واحدة عند تهيئة القاعدة)، ولا تُحفظ في المستودع |
| `BLOB_READ_WRITE_TOKEN` أو `BLOB_STORE_ID` | يضيفها Vercel عند ربط متجر Blob خاص بالمشروع |

## التشغيل والاختبار محلياً
```
cd app && npm install && cd ..
node dev/server.mjs --port 8787 --data /tmp/ev-data --reset --instances 2
node test/api-cloud.mjs      # 30 اختباراً للخادم والأمان
node test/e2e-cloud.js       # المتصفح كاملاً على النسخة السحابية
node test/e2e.js             # النسخة الأوفلاين
```
