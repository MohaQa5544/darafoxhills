# سجل الأداء — البرنامج (الإصدار 1.0 أوفلاين)

يعمل من مجلد دروب بوكس المشترك دون خادم: افتح `index.html` بمتصفح Chrome/Edge، واختر مجلد البرنامج كمكان للبيانات، فتُحفظ السجلات ملفات JSON داخل `data/` ويتشاركها الفريق عبر المزامنة.

- `bank.js` بنك الأسئلة والأوزان الافتراضية والسلّم والمسميات · `texts.js` نصوص الخطابات
- `store.js` التخزين (مجلد / متصفح) · `core.js` الدخول والتوجيه ومحرك الاحتساب
- `screens.js` الشاشات الرئيسية · `eval.js` شاشة التقييم · `review.js` المقارنة والاعتماد · `reports.js` الخطابات والتقارير · `settings.js` الإعدادات
- `users.local.js` قائمة المستخدمين الأولية (لا تُرفع إلى المستودع) · `build.py` يُنتج `dist/index.html` ملفاً واحداً
- الاختبار الشامل: `node test/e2e.js` (Playwright) يمرّ بكل الرحلة من الدخول إلى التقرير.
