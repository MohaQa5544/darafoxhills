# إدارة الحضور والانصراف — التكليف المسائي (إدارة الاستثمار)

برنامج ويب بسيط (ملف واحد، يعمل دون إنترنت) لتسجيل حضور المكلفين مساءً وطباعة التقرير الشهري.

## الاستخدام
1. افتح `index.html` في المتصفح (أو `dist/attendance.html` بعد البناء).
2. **الإدخال اليومي:** اختر لكل موظف: حاضر (في الإدارة / في الموقع + رقم مشروع أو مشروعين) أو إجازة براتب / عارضة / مرضية.
3. **العطل الرسمية:** أضف العطلة (عيد الفطر، عيد الأضحى، اليوم الوطني، اليوم الرياضي، أو اسم آخر) مع تاريخ البداية والنهاية.
4. **التقرير الشهري والطباعة:** بيان مجمّع في صفحة واحدة لمهندسي المشاريع، ثم كشف توقيعات لكل مهندس، ثم كشفا قسم العقارات.

## البيانات
- تُحفظ في المتصفح (localStorage). حمّل **نسخة احتياطية** من صفحة «الموظفون والإعدادات» بشكل دوري.
- بيانات الموظفين الحقيقية (بطاقات شخصية، آيبان) **لا تُرفع للمستودع**: ضعها في `data.local.js` (مُتجاهَل في git) بالشكل:
  `window.LOCAL_DATA = { employees: [...], records: {} };`
  بدونه يعمل البرنامج ببيانات تجريبية يمكن تعديلها من صفحة الإعدادات.

## البناء لملف واحد
```
python3 build.py   # ينتج dist/attendance.html مع الشعارات و data.local.js إن وُجد
```
